### 3.2 溯源能力（"某书某页"级）

每个索引 chunk 带：`source`（档案名）+ `offset`（字符偏移）+ `section`（篇目名）+ `page`（页码）+ `confidence`（exact/approx），**覆盖率 9132/9132**。

- 实现：`src/knowledge/toc_index.py`（双方案：精确锚定 exact / 页码比例插值 approx）
- 页码粒度：篇目起始页（来自档案目录），非逐页 OCR 页码

### 3.3 知识图谱（核心成果）

- **473 实体 / 282 关系**（类型：person 143 / location 251 / event 23 / army 53 / organization 21 / document 15 / other 5）

```powershell

# 4. 命令行测试 / 启动 Web
```

- `RED_ARCHIVE_TOC_XLSX`（可选，仅重新生成 book_toc.json 时需要）
- `RED_ARCHIVE_PDF_DIR`（可选，build_pipeline 提取 PDF 用）

## 8. 协作规范要点（防环境不兼容）

详见 `docs/CODE_STYLE.md`，核心 5 条：
1. **统一 LF + UTF-8**（.gitattributes 已强制，防 CRLF 合并冲突）
2. **禁止硬编码绝对路径**（用 `RED_ARCHIVE_PROJECT_DIR` 或代码推导）
3. **依赖锁版本**：`requirements-lock.txt`（精确） + `requirements.txt`（下限），新增依赖同步更新
4. **合并前**：`git fetch && git rebase origin/main` + `python -m pytest tests/`
5. **Commit Message**：Conventional Commits（feat/fix/docs/refactor/test/chore）
