## 2. 技术路线

首选：`CosyVoice3` 本地 Docker 侧载服务。

推荐镜像：

```text
neosun/cosyvoice:v3.4.0
```

优点：
- 支持中文、四川话、广东话、东北话、上海话等方言。
- 支持自定义音色克隆：上传参考音频即可。
- 提供 OpenAI 兼容 TTS 接口：`/v1/audio/speech`。
- 项目 Flask 服务只需调用 `http://127.0.0.1:8188`，不需要把模型装进现有 venv。


如果中文 `-F text=` 出现乱码，改用 Python 注册脚本，保存为 `register_sichuan_voices.py`：

```python
from pathlib import Path
import httpx

base = Path(r"D:\agent kf\Red-Aechives-Agent\data\tts")
text = "我给你摆嘛，我们这坨是红军长征走过嘞地方。1935年、1936年，红军从这坨过江、开会，老辈子到现在都还记得倒。你要来耍嘛，我带你去qio一眼当年嘞渡口，再整碗小面给你吃哈。"

for name in ("sichuan_male", "sichuan_female"):
    audio = base / f"{name}_ref.wav"
    with audio.open("rb") as f:
        r = httpx.post(
            "http://127.0.0.1:8188/v1/voices/create",
            files={"audio": (audio.name, f, "audio/wav")},
            data={"name": name, "text": text},
            timeout=120,
        )
    print(name, r.status_code, r.text)
```

## 6. 把 CosyVoice 接进 Flask 项目

### 6.1 在 `.env` 增加配置

```env
DIALECT_TTS_URL=http://127.0.0.1:8188
```

### 6.2 修改 `src/web/tts.py`

在文件顶部增加：

```python
import urllib.request
import json

DIALECT_TTS_URL = os.environ.get("DIALECT_TTS_URL", "http://127.0.0.1:8188")

DIALECT_VOICE_IDS = {
    "sichuan": {
        "male": "sichuan_male",
        "female": "sichuan_female",
    },
    "yunnan": {
        "male": "yunnan_male",
        "female": "yunnan_female",
    },
}
```

增加一个 CosyVoice 合成函数：

```python
def _synth_with_cosyvoice(text: str, gender: str, accent: str):
    voice = DIALECT_VOICE_IDS[accent]["male" if gender == "male" else "female"]
    payload = json.dumps({
        "input": text,
        "voice": voice,
        "response_format": "wav",
    }).encode("utf-8")
    request = urllib.request.Request(
        DIALECT_TTS_URL + "/v1/audio/speech",
        data=payload,
        headers={"Content-Type": "application/json"},
    )
    with urllib.request.urlopen(request, timeout=180) as response:
        audio = response.read()
    return audio, voice, "audio/wav"
```

在 `synthesize_speech` 中，进入 edge-tts 之前增加：

```python
    if accent in DIALECT_VOICE_IDS:
        try:
            return _synth_with_cosyvoice(text, gender, accent)
        except Exception:
            pass
```

这样：
- `accent == "sichuan"` 时优先走 CosyVoice 四川话。
- CosyVoice 没启动时自动回退到 edge-tts 文字风格。

## 10. 注意事项

- 下载和安装占用的是硬盘，不是运行内存。
- 建议 Docker Desktop 磁盘镜像位置放在 D 盘。
- 4GB 显存可能跑不动 CosyVoice3，遇到 OOM 就换 300M 或 CPU 方案。
- `prompt_text` 必须和参考音频实际朗读内容完全一致，否则克隆效果会明显变差。
